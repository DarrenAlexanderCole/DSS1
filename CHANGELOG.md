# Changelog

## 1.5
- **Export for Serato DJ** (Chop → EXPORT → SERATO DJ): a tagged copy of the song where pads 1–8 of the current
  bank become hot cues 1–8 (Serato colours, pad names) and the loop memories become saved loops. Copies go to a
  `Serato` folder in the crate, which the library ignores.
- Thin red outlines on the Chop page mark the pads and loop memories that export to Serato.

## 1.4
- FF plays at 1.5x; prev / next track keys moved under the transport.
- Source text sits above the compressor.
- Bigger compressor knobs, with a 4th "knob" that turns the compressor on and off.
- Bigger opto compressor with a large ON/OFF key.
- MPC Sample: MMC play and MIDI real-time start / continue / stop now drive the transport.

## 1.3
- REW plays the tape backwards and FF forwards, with the reels turning; prev / next track keys.
- MIDI transport on the Chop page.
- "Hot" FX encoder: click an FX knob to select it, twist the encoder for depth, click the encoder to toggle it.
- A MIDI slider can map to pitch.
- VU meters follow the deck volume and sit at a realistic level (0 VU = −14 dBFS).
- MIDI Learn for more message types (NRPN, program change, aftertouch, SysEx, MMC) and a MIDI Monitor window
  with Copy Log.

## 1.2
- CL 1B-style tube opto compressor on the Radio deck, next to the original compressor.
- Chop pads show their computer key until first pressed.
- Attack and release controls on the Performance pad.
- Smaller loop memory keys; fraction loops (1/2, 1/4, 1/8, 1/16 bar) and a 32-bar loop.
- Eject returns to the Crate.

## 1.0 – 1.1
- First versions: drop and import, the Crate, the Radio deck, Chop with MPC export, the Performance pad and MIDI.
